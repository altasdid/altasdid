# Hi, I'm Md. Al Tas Did Ul 👋

**Mechatronics Engineer** | Robotics • Control Systems • Embedded Systems • IoT

I'm a Mechatronics Engineering graduate from **Rajshahi University of Engineering & Technology (RUET)**. I build robots that work in the real world, from bomb disposal prototypes to Mars rovers, and I enjoy leading teams that turn ideas into working machines.

## 🔧 What I Work With

- **Languages:** C, C++, Python
- **Robotics:** ROS2, Gazebo, RViz, MoveIt, SLAM, NAV2
- **Embedded & IoT:** Arduino, Raspberry Pi 5
- **Vision / ML:** OpenCV, YOLOv8, YOLOv11
- **Design & Simulation:** AutoCAD, Blender, Proteus, Microchip Studio
- **Industrial:** PLC, HMI, preventive maintenance

## 🚀 Featured Projects

- **HADES X03:** Bomb disposal robot prototype for the Bangladesh Army (ROS, SLAM, NAV2, 5-DOF arm)
- **MARS Rover (Team Ogrodoot):** Electrical and drive system, load controller, rocker-bogie suspension
- **Four-Legged Spider Robot:** Human detection with YOLOv11 on Raspberry Pi 5, GPS-aided localization
- **Stair-Climbing Delivery Robot (B.Sc. Thesis):** ROS-based autonomous delivery with face-recognition verification
- **High-Speed Line Follower:** PID-controlled, IR array, modular battery
